Windows 10/11 · 64-bit

—
Встановити GnathoLineInstall GnathoLine

Один малий інсталятор з усіма модулями. Компонент «ШІ для КТ» (Python/CUDA + моделі, ~1,9 ГБ) програма завантажить сама при першому вході в модуль КТ — як add-on'и в Blender for Dental. На картах NVIDIA сегментація йде на GPU, без NVIDIA — на процесорі (повільно). Той самий файл програма ставить і як оновлення.

One small installer with every module. The “AI for CT” component (Python/CUDA + models, ~1.9 GB) is downloaded by the app itself the first time you open the CT module — like add-ons in Blender for Dental. Segmentation runs on the GPU on NVIDIA cards, otherwise on the CPU (slow). The same file is what the in-app updater installs.

—

Офлайн-варіант: повний інсталятор з уже вбудованим компонентом ШІ — для клінік без швидкого інтернету. Якщо файлів кілька, завантажте усі в одну теку й запустіть Setup.exe.

Offline option: full installer with the AI component already embedded — for clinics without fast internet. If there are several files, download all of them into one folder and run Setup.exe.

macOS · Apple Silicon

—
Завантажити .pkgDownload .pkg

Встановлює GnathoLine.app у «Програми». Якщо macOS каже, що розробника не підтверджено: правий клік → Відкрити.

Installs GnathoLine.app into Applications. If macOS reports an unverified developer: right-click → Open.

Модулі вмикаються ключами — як add-on'и в Blender for Dental: програма ставиться вільно, на стартовому екрані невстановлені модулі позначені «🔒 Встановити». Натисніть модуль → «Надіслати розробнику» (лист із кодом машини) → вставте отриманий ключ. Ключ прив'язаний до одного комп'ютера; ключі на різні модулі складаються.

Modules are unlocked with keys — like add-ons in Blender for Dental: the app installs freely, modules not yet installed show “🔒 Install” on the start screen. Click the module → “Send to developer” (an e-mail with your machine code) → paste the key you receive. A key is bound to one computer; keys for different modules add up.

Маніфест для автооновлення: https://gnathohub.com/gnatholine/latest.json. Усі дані пацієнтів лишаються на вашому комп'ютері — програма надсилає лише запит версії.

Auto-update manifest: https://gnathohub.com/gnatholine/latest.json. Patient data never leaves your computer — the app only requests the version.
