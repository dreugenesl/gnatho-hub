GnathoLine

The patient's articulator, built from the scans you already take.

Download · current versionRequest the evaluation build

GnathoLine mounts intraoral scans in a virtual articulator on the patient's own hinge axis, sets the condylar guidance from bite registrations or recorded movements, and shows occlusal contacts live while the jaw moves. CBCT, motion recordings and lab cases work in the same scene. Each module is a self-contained workflow with its own loading, tools and export; meshes pass between modules without re-import.

Data

What goes in, what comes out.

Intraoral scansPLY and OBJ with texture, STL. Medit export folders are recognised automatically.
CBCTDICOM series; segmentation runs locally with an embedded runtime, no cloud upload.
Jaw motionModjaw, Zebris, Itaka and Medit recording exports.
CondylographyCadiax PDF reports.
Lab casesWeb-viewer exports of third-party dental CAD systems.
OutputMounted jaws as STL/PLY in the articulator coordinate system, articulator settings, PDF reports, splint solids, a case package for the lab, upload to the clinic's record system.
PlatformsmacOS (Apple Silicon) and Windows 10/11 64-bit. Offline installers; AI segmentation uses the GPU on NVIDIA cards and Apple Silicon, with CPU fallback.
AvailabilityPilot per-workstation licences in Ukraine; a time-limited evaluation build for clinics and labs. Commercial release planned for Q1 2027, Ukraine first, then the EU.
